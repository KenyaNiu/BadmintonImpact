## 5. Agreement / 承诺条款

By submitting this form, the applicant and PI agree to:

提交本表即表示申请人及导师同意：

1. Use BadmintonGRF data **only** for approved non-commercial research and education.  
   仅将数据用于已批准的非商业科研与教学用途。
2. **Not** attempt to identify participants or redistribute raw data, videos, or access credentials.  
   **不得**尝试识别受试者身份，亦不得再分发原始数据、视频或访问凭证。
3. **Not** use data for surveillance, biometric profiling, or commercial product development without written permission.  
   未经书面许可，**不得**将数据用于监控、生物特征分析或商业产品开发。
4. Store data securely and limit access to authorized team members.  
   安全存储数据，并限制仅有授权团队成员可访问。
5. Cite BadmintonGRF and this work in publications that use the data.  
   在基于该数据发表的成果中引用 BadmintonGRF 及相关论文。
